11. GUIA COMPLETO DE USO - SISTEMA SKU
===========================================

O que é SKU?
-----------
SKU (Stock Keeping Unit) é um código único que identifica cada produto no sistema.
Formato: SKU-XXXX (ex: SKU-0001)

Como Usar o Sistema de SKU:
---------------------------

1. ENCONTRAR O CÓDIGO SKU:
   • Abra o ficheiro SKU_CODIGOS.html no navegador
   • Procure o produto desejado (organizado por categorias)
   • Copie o código SKU (ex: SKU-0042)

2. FAZER UMA ENCOMENDA:
   • Aceda ao módulo Encomendas no sistema
   • Selecione o Fornecedor
   • Na secção "Produtos (use Código SKU)":
     - Cole/digite o código SKU (ex: SKU-0001)
     - Digite a Quantidade desejada (ex: 5)
     - Clique em "+ Adicionar Produto" para mais itens
   • O total de itens é mostrado automaticamente em baixo
   • Clique em "Criar Encomenda"

Quero encomendar:
- 10 unidades de Água Mineral (SKU-0001)
- 5 unidades de Arroz Carolino (SKU-0002)

7. CORREÇÕES - CÁLCULO DE PREÇO TOTAL (15/01/2026)
===========================================

PROBLEMA IDENTIFICADO:
O total da encomenda não estava aparecendo (€ 0.00) quando o utilizador 
digitava a quantidade de produtos, apesar do sistema de SKU estar funcionando.

CAUSAS IDENTIFICADAS:
1. cost_price era retornado como string ("0.09") - não havia conversão para número
2. Se a quantidade era digitada antes do produto estar totalmente carregado, 
   o cache estava vazio e o cálculo retornava 0
3. Falta de logs de debug para acompanhar o fluxo
